# 공모전 탐색 (contest-scout)

## 1. 조건 확인

요청에 없으면 한 번에 짧게 묻는다(이미 알고 있으면 묻지 않는다):
- 분야 (IT·해커톤 / 아이디어·기획 / 공공데이터 / 디자인 / 영상 / 글쓰기 / 무관)
- 마감 범위 (예: 4주 이내)
- 개인 / 팀
- 준비에 쓸 수 있는 시간 (주당 몇 시간)

## 2. 수집 (무료 도구만)

공개 목록 페이지만 읽는다. 로그인 필요 페이지는 건너뛴다.

| 사이트 | 특징 |
|---|---|
| 위비티 wevity.com | 전 분야 공모전, 분야별 목록 |
| 씽굿 thinkcontest.com | 전 분야 공모전 |
| 컨테스트코리아 contestkorea.com | 전 분야, 대학생 대상 많음 |
| 링커리어 linkareer.com | 대외활동·공모전 (JS 렌더링 → Playwright 필요할 수 있음) |
| 데이콘 dacon.io | 데이터·AI 경진대회 |

- 먼저 WebSearch로 "<분야> 공모전 <연도>" 등을 검색하고, 목록 페이지는 WebFetch로 읽는다.
- WebFetch 결과가 비어 있으면 Playwright MCP로 연다.
- 같은 공모전이 여러 사이트에 있으면 하나로 합친다(제목+주최 기준).
- 이미 마감된 공모전은 제외한다.

## 3. 적합도 평가

각 후보를 아래 기준으로 상/중/하 평가한다.
- **조건 일치**: 분야, 마감, 개인/팀
- **준비 부담**: 제출물 양 대비 남은 기간
- **경쟁·보상**: 상금, 수상 인원(수상 인원이 많을수록 확률↑), 주최 신뢰도
- **포트폴리오 가치**: 사용자 전공·관심과의 연관성

## 4. 결과

- 상위 5개 이하를 표로 보여준다: 이름, 주최, 마감(D-day), 제출물, 적합도, 한 줄 이유, 링크
- `contests/_탐색결과_<YYYY-MM-DD>.md`에도 저장한다.
- 마지막에 "어떤 걸 시작할까요?"라고 묻고, 선택하면 `rubric-parser`로 넘어간다.
- 상세 공고를 확인하지 않은 정보(상금 등)는 "목록 기준"이라고 표시한다.
